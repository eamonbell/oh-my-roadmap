# /milestone:status

Render milestone status, current wave, task ownership, worker notes, open blockers, review findings, verification status, relevant code/docs context, and next legal action. Use `roadmap_engineer_search_context` for worker notes, blockers, review findings, decisions, and risks; expand selected entries with `roadmap_engineer_read_context` only when full detail is needed. Use the built-in `ask` tool only if status reporting uncovers a decision or approval needed before the next legal action.
